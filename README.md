# DocuSahulat
# An AI-powered Multilingual Document Query & RAG Assistant
DocuSahulat is an intelligent document interaction platform designed to bridge the gap between complex official documents and everyday users. Using Retrieval-Augmented Generation (RAG), it allows users to upload dense PDFs—such as university handbooks, policy guides, or municipal bylaws—and receive instant, accurate answers in plain English or Urdu with direct page citations.
# Problem Statement
Important policy documents, academic handbooks, and government guidelines are often long, dense, and difficult to search. Reading through hundreds of pages to find specific information creates information fatigue, especially for non-native English speakers or citizens unfamiliar with bureaucratic language.
# Solution
DocuSahulat solves this by combining Retrieval-Augmented Generation (RAG) with a multilingual conversational interface.
1. Instant Information: Upload any PDF and ask questions in plain language.
2. Exact Citations: Displays precise page numbers and source text to eliminate hallucinations.
3. Multilingual Support: Delivers answers in both English and Urdu for enhanced accessibility.
# Tech Stack
Frontend: Streamlit / Next.js (Tailwind CSS, Radix UI components)

Backend Framework: Python, LangChain / LlamaIndex

AI & LLM: OpenAI API / Hugging Face Open-Source LLMs

Vector Database: ChromaDB / FAISS

PDF Processing: PyPDF / pdfplumber

Deployment: Streamlit Community Cloud / Vercel
